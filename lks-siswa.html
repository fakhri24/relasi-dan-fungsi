Bagian A · Ketika Satu Rumus Lurus Gagal (Sinkron Slide 7)

Sebuah mall memberlakukan kebijakan: Drop-off $\le 15$ menit gratis, jam pertama Rp 5.000, jam berikutnya +Rp 3.000, dan tarif maksimal harian Rp 35.000. Jika pengelola memaksakan 1 rumus linear kaku $f(x) = 3.000x + 5.000$, hitunglah keanehan yang terjadi:

Kondisi 1: Hanya Drop-off (6 Menit = 0.1 Jam)
Tagihan Rumus Kaku: $3000(0.1) + 5000 =$ Rp 5.300.
Mengapa pelanggan akan protes keras?:
Kondisi 2: Parkir Menginap (24 Jam)
Tagihan Rumus Kaku: $3000(24) + 5000 =$ Rp 77.000.
Padahal aturan mall menetapkan batas maksimal flat: Rp 35.000 (rumus kaku terlalu mahal).

💡 Kesimpulan: Karena kondisi tarif berubah-ubah tergantung interval waktu, kita membutuhkan Fungsi Sepenggal (Piecewise Function).

Bagian B1 · Membaca Notasi Kurung Kurawal $\{ $ (Sinkron Slide 8)

Diberikan fungsi piecewise 3 cabang berikut:

$$f(x) = \begin{cases} 4, & \text{jika } 0 \le x \le 1 \quad \text{(Cabang 1)} \\ 2x + 2, & \text{jika } 1 < x \le 4 \quad \text{(Cabang 2)} \\ 10, & \text{jika } x > 4 \quad \text{(Cabang 3)} \end{cases}$$

Bagian B2 · Rahasia Titik Penuh (●) dan Titik Terbuka (○)

Dalam fungsi sepenggal, pertemuan antar garis cabang sering memiliki titik batas kritis.

Titik Penuh (●) Artinya nilai ikut masuk ($\le$ atau $\ge$)
Titik Terbuka (○) Artinya nilai batas TIDAK ikut ($<$ atau $>$)
Tantangan: Sketsa Grafik Fungsi Bertingkat:

Gambarkan fungsi $g(x) = \begin{cases} 3, & 0 \le x \le 2 \\ x + 1, & 2 < x \le 5 \end{cases}$. Perhatikan titik di batas $x = 2$!

Di titik $x = 2$: Cabang 1 bernilai $3$ diberi tanda [ ● / ○ ], Cabang 2 bernilai $3$ diberi tanda [ ● / ○ ].
